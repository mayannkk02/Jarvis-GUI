# Jarvis AI 🤖

A futuristic AI assistant interface inspired by Iron Man's J.A.R.V.I.S.

## 🚀 Features

* 🔵 Animated Jarvis Orb UI
* 💬 Chat Interface
* 📊 System Status Panel
* 🎨 Modern Glass UI Design
* ⚡ Fast performance with Vite

## 🛠 Tech Stack

* React + Vite
* TypeScript
* Tailwind CSS
* shadcn-ui

## 📂 Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/mayannkk02/Jarvis-GUI.git
cd Jarvis-GUI
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

```bash
npm run dev
```

👉 Open in browser:

```
http://localhost:8080
```
